## 🎯 Overview

StockLens AI is an open-source, self-hostable stock research playground that runs a
9-step AI analysis pipeline on any US-listed ticker symbol. It fetches real-time market
data and recent news, deduplicates and summarises articles using a local LLM
(Mistral 7B via Ollama), classifies sentiment, extracts corporate events, and generates
structured analytical insights — all streamed live to the browser via Server-Sent Events
as each pipeline step completes. The full stack (FastAPI backend, Next.js frontend,
PostgreSQL, Redis, Ollama) runs on a single machine via Docker Compose, with no external
AI APIs required by default.

## Key Features

- ⚡ **Real-time streaming analysis** via Server-Sent Events (SSE)
- 🧠 **9-step AI pipeline** with deterministic + LLM hybrid processing
- 🏠 **Fully self-hostable** (no external APIs required by default)
- 🔌 **Pluggable LLM providers** (Ollama, OpenAI, NVIDIA APIs)
- 📊 **Hybrid market data sources** (YFinance + Alpha Vantage + NSE)
- 🧹 **Advanced news deduplication** using SimHash
- 📈 **Deterministic sentiment aggregation (100% invariant)**
- 🔐 **Rate limiting + idempotency guarantees**
- 📡 **Observability stack** (Prometheus + Grafana + Loki)
- 🐳 **One-command Docker deployment**

## 🚀 Getting Started

### Prerequisites

- Docker Desktop ≥ 24 (or Docker Engine + Compose plugin ≥ 2.20)
- 8 GB RAM available to Docker (16 GB recommended when Ollama uses CPU inference)
- 10 GB free disk space (Mistral 7B model is ~4.1 GB)
- Git

### 1. Clone the repository

```bash
git clone https://github.com/govindp47/stocklens-ai.git
cd stocklens-ai
```

### 2. Create the environment file

```bash
cp infra/.env.example infra/.env
```

Open `infra/.env` and set the required values.

### 3. Start all services

```bash
docker compose -f infra/docker-compose.yml up -d
```

This starts 9 services: `api`, `frontend`, `db`, `redis`, `ollama`, `nginx`,
`prometheus`, `grafana`, `loki`. On first run the images are built and the Ollama
base image is downloaded — allow 3–5 minutes.

### 4. Pull the Mistral 7B language model

```bash
docker compose -f infra/docker-compose.yml exec ollama ollama pull mistral:7b-instruct
```

This downloads the ~4.1 GB model weights. Run this once; the weights are stored in a
persistent Docker volume (`ollama_models`) and survive container restarts.

### 5. Verify the stack and open the application

```bash
# All services should be (healthy)
docker compose -f infra/docker-compose.yml ps

# Backend health check
curl http://localhost:8000/health
# Expected: {"status":"healthy","checks":{"database":"ok","redis":"ok","ollama":"available"}}
```

Open **<http://localhost:3000>** in your browser, enter a ticker symbol (e.g. `AAPL`),
and click **Analyse**. The 9-step pipeline runs and each panel populates in real time.

## Architecture Overview

StockLens AI uses a clean-architecture layered design:

```bash
Browser (Next.js SPA)
    │  POST /api/v1/analyze   GET /api/v1/analyze/stream/{run_id}
    ▼
Nginx (SSL termination, rate limiting, static assets)
    ▼
FastAPI (Python 3.11+, asyncio, single Uvicorn process)
    ├── REST API Routers (/api/v1/analyze, /results, /news, /metrics)
    ├── SSE Stream Router  ← Redis Pub/Sub fan-out
    └── Background Task: PipelineOrchestrator (9 steps, 90s watchdog)
         ├── Steps 1–2  (TickerValidator, MarketDataCollector)  ← Hybrid market data
         ├── Steps 3–4  (NewsRetriever, NewsDeduplicator)       ← RSS feeds
         └── Steps 5–9  (Summarizer, Sentiment, Events,         ← Ollama / OpenAI / NVIDIA
                          Insights, ReportAssembler)
    ▼                    ▼                  ▼                   ▼
PostgreSQL 15         Redis 7            Ollama            Market Data
(report storage)  (SSE events, cache,  (Mistral 7B)    Alpha Vantage (primary)
                   rate limiting)                       NSE (Indian stocks)
                                                        YFinance (fallback)
```

For the full architecture specification see
[docs/01_SYSTEM_ARCHITECTURE.md](docs/01_SYSTEM_ARCHITECTURE.md).

## Pipeline Deep Dive

The StockLens pipeline executes 9 sequential steps:

1. **Ticker Validation** — validates and resolves ticker
2. **Market Data Collection** — fetches price + computes trend & volatility
3. **News Retrieval** — collects latest articles
4. **Deduplication** — removes duplicates using SimHash
5. **Summarization** — LLM summarises each article
6. **Sentiment Classification** — per-article + aggregated sentiment
7. **Event Extraction** — detects key corporate events
8. **Insight Generation** — structured AI-generated analysis
9. **Report Assembly** — deterministic final report

Each step streams results live to the UI via SSE.

## API Reference

The backend exposes five REST endpoints:

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/v1/analyze` | Submit a ticker for analysis; returns `run_id` (202) |
| `GET` | `/api/v1/analyze/stream/{run_id}` | SSE stream of pipeline step events |
| `GET` | `/api/v1/results/{run_id}` | Retrieve the full assembled report JSON |
| `GET` | `/api/v1/news/{ticker}` | Latest deduplicated article list for a ticker |
| `GET` | `/api/v1/metrics` | System performance and error rate aggregates |

Interactive documentation (Swagger UI) is available at **<http://localhost:8000/docs>**
while the stack is running.

For detailed request/response schemas and examples, see the in-app
[API Docs page](http://localhost:3000/docs) or the auto-generated
[OpenAPI spec](http://localhost:8000/openapi.json).

## Configuration

### LLM Providers

Three provider backends are supported, selectable per-request via the `X-LLM-Provider`
request header:

| Provider | Header value | Mode | Model | Notes |
|---|---|---|---|---|
| Ollama | *(default)* | Local | `mistral:7b-instruct` | No API key required |
| OpenAI | `openai` | Remote | User-selected | Requires `X-OpenAI-Key` header |
| NVIDIA NIM — LLaMA | `nvidia-llama` | Remote (free tier) | `meta/llama-3.1-8b-instruct` | Requires `NVIDIA_API_KEY` env var |
| NVIDIA NIM — Mistral | `nvidia-mistral` | Remote (free tier) | `mistralai/mistral-7b-instruct-v0.3` | Requires `NVIDIA_API_KEY` env var |
| NVIDIA NIM — DeepSeek | `nvidia-deepseek` | Remote (free tier) | `deepseek-ai/deepseek-r1-distill-llama-8b` | Requires `NVIDIA_API_KEY` env var |

NVIDIA free-tier API keys are available at <https://integrate.api.nvidia.com>. Set
`NVIDIA_API_KEY` in `backend/.env` to enable NVIDIA models. No key is required for
the default Ollama mode.

### Market Data Providers

The `HybridMarketDataProvider` tries multiple sources in order, depending on the market:

**Global stocks (US, EU, etc.):**

1. **Alpha Vantage** (primary for quotes and company info)
2. **YFinance** (fallback)

**Indian stocks (`.NS`, `.BO` suffix or Redis-cached symbols):**

1. **Alpha Vantage** (primary for quotes)
2. **NSE API** (Indian exchange — company info and quote fallback)
3. **YFinance** (final fallback)

Set `ALPHA_VANTAGE_API_KEY` in `backend/.env` (free tier: <https://www.alphavantage.co>).

### Rate Limiting

- Sliding window, Redis-based (Lua script, atomic)
- Per-IP limits — default: **10 requests / 60 seconds**
- Exceeding the limit returns `429 Too Many Requests` with a `Retry-After` header

## Optional: OpenAI Model Switching

To use OpenAI's models instead of the local Ollama LLM:

1. Open the **Settings** modal (⚙ icon in the top-right corner of the UI).
2. Enter your OpenAI API key in the masked input field.
3. Select the OpenAI model from the model dropdown.
4. Click **Save**. The key is held in browser memory only and is never written to
   `localStorage`, cookies, or any server storage.

The key is transmitted to the backend as the `X-OpenAI-Key` request header on each
`POST /api/v1/analyze` call only, and is discarded from server memory after the
pipeline completes.

## Troubleshooting

### Ollama not responding

- Ensure model is pulled:

```bash
ollama pull mistral:7b-instruct
```

### High memory usage

- Reduce model size OR increase Docker RAM

### Redis connection errors

- Verify Redis container is healthy:

```bash
docker compose ps
```

### SSE not streaming

- Ensure Nginx has:

```bash
proxy_buffering off;
```

## Performance Notes

- Average pipeline latency: **5–20 seconds**
- LLM inference dominates latency (~70%)
- Recommended:
  - 16GB RAM (CPU inference)
  - GPU improves performance significantly
- Concurrent runs limited by semaphore (LLM safety)

## Security

- API keys are **never persisted**
- Rate limiting prevents abuse
- Input validation via strict schemas
- LLM outputs sanitized and parsed safely
- Redis + DB access isolated via Docker network

## FAQ

**Q: Does this give financial advice?**  
No. It is strictly an informational research tool.

**Q: Can I run this without internet?**  
Yes (except market/news APIs) if using local Ollama.

**Q: Can I use my own LLM?**  
Yes — implement the `LLMProvider` interface.

**Q: Why SSE instead of WebSockets?**  
SSE is simpler, reliable, and fits one-way streaming perfectly.
